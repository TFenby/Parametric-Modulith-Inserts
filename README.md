# Parametric Modulith Inserts

Browser-based generator for drop-in divider inserts for Modulith (Jerrari Gen2) drawers.
Tweak parameters, preview in 3D, and download an STL — OpenSCAD runs in your browser via WebAssembly.

**Use it:** https://tfenby.github.io/Parametric-Modulith-Inserts/

The model is [`modulith_insert.scad`](modulith_insert.scad); it also opens in desktop OpenSCAD with the Customizer.
